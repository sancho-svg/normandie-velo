Installation sur l'écran d'accueil

Une fois cette application hébergée sur une adresse HTTPS, tu pourras l'ajouter comme une application sur Android.

  1. Ouvre l'adresse de l'application dans Chrome.
  2. Appuie sur « Installer » ou sur ⋮ puis « Ajouter à l'écran d'accueil ».
  3. Confirme : l'icône Normandie Vélo apparaîtra sur ton téléphone.

Important : ouvrir simplement un fichier HTML téléchargé ne suffit généralement pas à installer une PWA. Il faut une adresse web sécurisée (HTTPS).
